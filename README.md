Entry for the [Your AI Therapist's Diagnosis](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41) competition on make.fun.

## What it does

Writes one original one-line diagnosis from an AI therapist to `/output/entry.txt`: a deadpan clinical finding about doomscrolling and main-character syndrome, with the punchline landing at the end. Deterministic: no randomness, no network, no model calls, and no reads outside the repo, so every run produces the same line.

## Run

```sh
node main.ts
```

Then read `/output/entry.txt`.
